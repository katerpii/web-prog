실행 방법
========================================

1. 이 플랫폼은 mySQL 서버를 필요로 합니다
----------------------------------------

```
docker pull mysql:8.0
```

<br><br>



2. 플랫폼을 실행
----------------------------------------

루트 디렉토리의 docker-compose.yml을 실행합니다.

```
docker compose up --build
```

그런 다음 http://localhost:3000 에 접속하세요.


<br><br>



3. 로그인
----------------------------------------

github 또는 google 계정으로 로그인할 수 있습니다.

<br><br>


4. 초대하기
----------------------------------------

google 이메일 계정을 초대합니다.
초대 링크가 발송되지 않았다면 스팸 메일을 참고하세요.

- github 계정은 유저 이메일이 없습니다. 초대 대상은 google 로그인 유저여야 합니다.
